```bash
#!/bin/bash

for ip in {1..254}; do
    ping -c1 192.168.1.$ip > /dev/null &
    if [ $? -eq 0 ]; then
        echo "Host 192.168.1.$ip is up" >> hosts_up.txt
    fi
done
```
This script will ping all hosts in the 192.168.1.0/24 subnet and if a host responds, it will write the IP address to a file named `hosts_up.txt`. The `-c1` option is used to send only one packet per host, making the ping operation silent.
